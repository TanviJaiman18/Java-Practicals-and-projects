# 🧮 Calculator – Java Swing MVC

A simple **Calculator application in Java** developed using **Java Swing** and the **MVC (Model-View-Controller) architecture**.

## 📌 Features

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* Percentage (%)
* Simple graphical user interface using Java Swing

## 🏗️ Project Structure

```text
Calculator/
│
├── main.java
├── Cviews.java
├── Cmodals.java
├── Ccontroller.java
└── README.md
```

### Model – `Cmodals.java`

Contains the calculator operations:

* Addition
* Subtraction
* Multiplication
* Division
* Percentage

### View – `Cviews.java`

Creates the graphical user interface using **JFrame, JLabel, JTextField, and JButton**.

### Controller – `Ccontroller.java`

Handles button clicks and connects the View with the Model.

### Main – `main.java`

Creates the Model, View, and Controller objects to start the calculator application.

## 🛠️ Technologies Used

* Java
* Java Swing
* MVC Architecture
* VS Code / Any Java IDE

## ▶️ How to Run

1. Install **JDK** on your computer.
2. Open the project folder in VS Code or any Java IDE.
3. Compile all Java files.
4. Run the `main` class.
5. Enter two numbers and click the required operation button.
