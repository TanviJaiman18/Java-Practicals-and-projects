Apache Tomcat & Basic Web Application
Aim
To install and configure Apache Tomcat and create and run a simple web application using an HTML page.

Technologies Used
HTML
Apache Tomcat 11
Web Browser
Project Structure
MyWebApp/
└── index.html
Procedure
Install and configure Apache Tomcat.
Create a folder named MyWebApp inside the webapps directory.
Create an index.html file inside MyWebApp.
Start the Tomcat server.
Open the application in a web browser.
Application URL
http://localhost:8080/MyWebApp/
Output
The web page displays a welcome message.

Result
A basic web application was successfully created and executed using Apache Tomcat.
