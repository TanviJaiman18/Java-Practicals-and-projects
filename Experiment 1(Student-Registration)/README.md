# Student Registration Form

A simple **Student Registration Form** developed using **Java Swing**.
This project demonstrates how to create a graphical user interface (GUI) in Java using Swing components.

## 📌 Project Overview

The Student Registration Form allows users to enter basic student information such as:

* Student Name
* Roll Number
* Gender
* Branch
* Terms & Conditions

The application also provides **Submit** and **Reset** buttons.

## 🛠️ Technologies Used

* **Java**
* **Java Swing**
* **AWT Event Handling**
* **JFrame**
* **JLabel**
* **JTextField**
* **JRadioButton**
* **JCheckBox**
* **JButton**

## ✨ Features

* Simple and user-friendly GUI
* Student name input
* Roll number input
* Gender selection
* Branch input
* Terms & Conditions checkbox
* Reset button to clear the form
* Window closes properly using the Exit option

## 🚀 How to Run

### 1. Install Java

Make sure Java JDK is installed on your computer.

Check Java installation using:

```bash
java -version
```

### 2. Open the Project

Open the project folder in **VS Code**, **NetBeans**, **IntelliJ IDEA**, or any Java-supported IDE.

### 3. Compile the Program

Open the terminal in the project folder and run:

```bash
javac StudentRegistrationForm.java
```

### 4. Run the Program

```bash
java StudentRegistrationForm
```

The Student Registration Form window will open.

## 🖥️ Working

1. Enter the student's name.
2. Enter the roll number.
3. Select the gender.
4. Enter the branch.
5. Accept the Terms & Conditions.
6. Click **Submit**.
7. Click **Reset** to clear the entered information.
